# TASK FILE TEMPLATE

Use this template when creating task files manually. In practice, tasks are
usually created via `devboard add "Title"` and then edited in place.

```markdown
---
id: <auto-generated>
title: <Task Title>
status: backlog
priority: medium
created: <auto-generated>
updated: <auto-generated>
project: <project-name>
tags: []
depends_on: []
cos: standard
---

## Description
What needs to be done and why.

## Acceptance Criteria
- [ ] Specific, testable condition
- [ ] Another condition

## Notes
Any additional context, links, or constraints.
```

## Field Descriptions

| Field | Description |
|-------|-------------|
| `id` | Auto-generated unique ID (integer, sequential) |
| `title` | Short, descriptive task name |
| `status` | Current workflow state (backlog, in-progress, review, done, blocked) |
| `priority` | low, medium, high, critical |
| `created` | ISO 8601 timestamp (auto-set) |
| `updated` | ISO 8601 timestamp (auto-updated on change) |
| `project` | Project or team name for grouping |
| `tags` | List of string tags for filtering |
| `depends_on` | List of task IDs that must be completed first |
| `cos` | Class of service: expedite, fixed-date, standard, intangible |
| `due` | Optional due date (ISO 8601) |
