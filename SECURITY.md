# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.1.x   | ✅ Yes              |
| 1.0.x   | ✅ Yes              |
| < 1.0   | ❌ No               |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening a
[GitHub Issue](https://github.com/stephanos8926-lgtm/DevBoard/issues) with
the "security" label.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to provide a fix within
7 days for critical issues.
